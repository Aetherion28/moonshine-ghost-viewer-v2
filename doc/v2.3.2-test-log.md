# Moonshine V2.3.2 — tester checklist

Please note your **game region** and **build checksum**. One clear try per check is enough. If something fails, tell us what you did and what happened; a short video helps.

## New and changed

- [ ] **Fast Any% starts:** use the Fast Any% stage loader. Pinna routes should start on the beach; Noki 3 should start outside the bottle.
- [ ] **Secret retry:** in Fast Any%, enter a secret, die, then finish it. The loader should continue to the next level. The retry should not replace a clean full-level PB.
- [ ] **Jump display:** enable it in Display > HUD and displays > Movement displays. Land, then jump immediately; try again after waiting a little. It should show 1f–6f, then Late, with a QF0–3 value beside it. Each landing starts a fresh count, and a savestate load clears the old result.
- [ ] **Buttslide jump cue:** turn on Buttslide display. Start a buttslide and check that the cue changes when you can jump. Try pressing A when it says ready, including while frame advancing.
- [ ] **GB timing:** from the usual no-hover GB-skip setup, try an early B press, the correct 9-frame press and a late press. Check the verdict, Y and vertical speed. This display measures timing, not whether you actually clipped through.
- [ ] **New display editors:** check that each preview matches the actual display, including `1f qf0`, `Late qf0` and `Ready / Waiting`. Open the Edit rows in Movement displays (also in Layout editor > Practice feedback). Move/recolour GB, Jump and Buttslide separately. Check that changing one leaves the others and wallkick alone.
- [ ] **Profile keyboard:** with D-pad Down as Menu Close and Pause, use Down while naming a profile. The keyboard should stay open and move the selection. Start saves; X+Start cancels; Down closes the ordinary menu afterward.
- [ ] **Layout profiles:** save a named layout with Y in Display > Layout profiles. Move or recolour something, save a second named profile and use A to swap between them. Check that your binds and practice rules stay the same.
- [ ] **Profiles after reboot:** reboot, apply a saved profile and check its name, layout, custom text and colours, including the new displays. Try cancelling an overwrite; the old profile should remain.

## A short check of existing features

- [ ] Open and close the menu on file select, then enter a level. Your settings and layout should still be there.
- [ ] Save and load all three state slots in your usual practice area. Hold Load once to check that gameplay stays still until you release it.
- [ ] Pause, hold A+B and press Advance. Try a short TAS with a checkpoint, then replay it through an area transition.
- [ ] Finish an ordinary IL with splits and a streak target. Check its result, PB and streak count; restart once and make sure the displays reset normally.
- [ ] Race or watch a saved ghost, and try free camera with smoothing. Your usual controls and ghost display should work.
- [ ] Japanese testers: check the movement and profile menus and the 52 translated achievement names for readable text. Achievement requirements should be unchanged. English-download testers playing JP should still see English Moonshine menus.

You do not need to repeat the full V2.3.0 checklist or test every level again.
