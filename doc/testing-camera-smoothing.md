# Camera smoothing and the new data folder — quick check

In **Practice > Free camera**, try **Camera smoothing** at **Off**, then
**0.1 s** and **1.5 s**. Move with the main stick and turn with the C-stick.

- Off should start and stop immediately, as before.
- With smoothing on, both movement and turning should ease in when you
  press the stick, change direction smoothly, and ease out when you let go.
  The longer setting should feel noticeably slower to start and stop.
- Check it while paused and with **Resume gameplay**, then close and reopen
  the menu to confirm your chosen duration stays selected.

## SD data

- Before updating, note one saved setting and a ghost or PB you use. Start
  the updated launcher and check that your settings, theme and practice data
  remain available. The app should still appear once in the Homebrew Channel.
- Check that your files are now under **Moonshine data** on the SD card,
  with settings in **moonshine.ini** and the theme in **theme**. Change one
  harmless setting, close the menu and reboot to check that it stays saved.
- If you normally share ghosts or save states/TAS projects to SD, save one
  and open it again. It should use **ghosts**, **states** or **tas** inside
  the data folder. Use new states/projects made with this build.
- If a crash happens during normal testing, send its matching files from
  **Moonshine data/crashes**. You do not need to cause a crash deliberately.

Report the game region, Wii/Wii U/Dolphin, what you pressed and what happened.
Keep existing data and backups while testing the update.
