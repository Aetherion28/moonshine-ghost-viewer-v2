# Moonshine Launcher FOXTROT — latest changes

**V2.3.0 pre-release · Build 5B0EC1B1**

- **Mario colour editor:** Recolour his cap, shirt, overalls, gloves, shoes, sunglasses and Sunshine shirt. Each part can use Original or Custom colours, including white. Skin keeps its normal colour. Find it under **Display > Appearance > Mario appearance > Mario colours**.

- **FLUDD and water colour editor:** Recolour FLUDD's body, metal, straps, tank and each of the four nozzles separately. Sprayed water and its highlights are editable too, including mist and splashes. The ocean and Yoshi juice keep their normal colours. Open **FLUDD colours** on the same Mario appearance page. Kept Mario and FLUDD colours survive rebooting.

- **Keep savestates on SD:** The new **Practice > Savestates > SD states** page saves a state as a file that survives powering off. Import it into a memory slot later, then use your normal Load action. This is experimental and needs real-console feedback. Use the same build, region and launcher setup, and return to the same level and episode. SD states are available through the launcher; standalone Dolphin patches do not include them.

- **More room for savestates:** Added 2 MiB of shared space for the three slots. Fixed a cause of failed overwrites that previously required deleting the old state first. If a replacement still cannot fit, your existing states are kept.

- **Full-level ghosts after loading a state:** Savestates now keep your ghost recording up to that moment. Loading lets you change the rest of the run while keeping the opening. Save, watch and export the finished ghost as usual; it is marked TAS and does not count as an ordinary PB.

- **Sunshine timer fixes:** Fixed its one-frame lead over QFT during practice pause, stepping and state loads. Normal QFT timing is unchanged. Original and Custom appearances both remain editable, including individual characters; changing a colour no longer switches the appearance automatically. Sunshine still rounds to hundredths, so QFT **11.845** can show as **11.85**.

If something looks wrong, send the level/episode, what you were doing and what happened. For a refused SD state, include the message shown.
